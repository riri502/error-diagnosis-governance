# project_background

## 这是什么

这是项目背景业务知识库的结构化目录，用于沉淀平台定位、产品范围、角色、终端、能力版图与产品优势。

## 怎么用

- 先读 `00_领域概述.md` 了解项目背景域的目标与边界
- 再读 `01_产品定位.md`、`02_平台角色与终端.md` 理解平台定位与角色终端
- 再读 `03_产品能力版图.md`、`04_产品优势与服务模式.md` 理解能力版图与服务模式
- 最后读 `05_管理控制台能力概览.md` 建立管理后台能力全景

## 阅读顺序

1. 领域总览层
2. 产品定位与角色终端层
3. 能力版图与服务模式层
4. 管理后台全景层

## 维护原则

- 只记录平台背景、产品范围、能力边界与角色终端口径
- 不在本目录中写具体后台配置规则和页面实现细节
- 尽量复用已有产品术语，避免新增背景概念
- 新知识优先落到对应编号模块，不回写为大一统长文

## 迁移原则

- 背景知识优先按认知顺序组织，保证首次阅读可建立全局理解
- 尽量复用现有产品术语，避免引入新的背景概念
- 后续新增背景材料按编号模块继续补齐

# 03_product_capability_landscape

平台产品能力由“人、财、事”通用服务与“开放连接”个性化定制数字服务共同构成。

## 1. 人
典型能力包括：
- 组织员工
- 组织管理
- 招聘管理
- 员工管理
- 假勤管理
- 薪酬管理
- 智能算薪
- 社保管理 / 社保服务
- 个税管理 / 个税服务
- 薪资代发
- 电子工资单
- 团体福利 / 福利关怀 / 红包管理 / 团体保险 / 文体活动

## 2. 财
典型能力包括：
- 发票管理
- 进项发票 / 销项发票
- 财务核算
- 智能记账
- 资产管理
- 费用管理
- 会计引擎
- 日常报销
- 对公报账
- 应收应付
- 账款管理
- 采购付款
- 电子档案
- 公费医疗
- 收费云

## 3. 事
典型能力包括：
- 审批管理
- OA 审批
- 公文
- 数据分析
- 智数报表
- BI 服务
- 智数平台
- 特色服务
- 智慧工会
- E 餐通
- 医招智付

## 4. 开放
典型能力包括：
- 应用开发
- CodeFriend 低代码平台
- 系统对接
- API 平台
- 连接平台

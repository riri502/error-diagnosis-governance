# member

## 这是什么

这是成员业务知识库的结构化目录，用于沉淀成员进入企业、停用与退出、成员组和外部人员相关知识。

## 怎么用

- 先读 `00_领域概述.md` 了解成员域边界，以及成员已从组织模块中独立出来
- 再读 `10_成员加入与邀请.md`、`11_成员退出与离职交接.md` 理解成员进入与退出链路
- 再读 `12_成员分组.md`、`13_外部人员.md` 理解成员分类与外部人员治理

## 阅读顺序

1. 领域总览层
2. 成员接入与退出层
3. 成员分类治理层

## 维护原则

- 只记录成员身份接入、成员分类和成员关系变化知识
- 不在本目录中写组织主数据、组织视图或平台组织底座规则
- 如涉及多维组织，只记录“成员挂载到组织底座”的边界事实，不越界描述组织建模
- 新知识优先落到对应编号模块，不回写为大一统长文

## 迁移原则

- 先保证成员生命周期主链路清晰，再补充分类与特殊成员场景
- 与组织域交叉时保持分域，避免把组织底座写入成员域
- 后续新增成员材料按编号模块继续补齐

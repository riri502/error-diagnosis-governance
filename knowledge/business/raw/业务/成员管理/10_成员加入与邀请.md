# 10_member_join_and_invitation

成员进入企业通常包含三个阶段：
- 用户完成平台注册
- 用户加入企业
- 管理员为用户分配权限

## 1. 邀请员工加入企业的方式

### 1.1 手机号邀请
路径：管理后台 -> 组织 -> 成员管理 -> 添加成员 -> 手机号邀请

特点：
- 支持发送短信提醒
- 用户登录平台后可通过弹窗确认加入企业

### 1.2 二维码 / 链接邀请
路径：管理后台 -> 组织 -> 成员管理 -> 添加成员 -> 二维码邀请

特点：
- 被邀请人扫码或点击链接后发起加入申请
- 管理员需在邀请记录中审批通过后才可成功加入企业

### 1.3 快速加入企业
路径：管理后台 -> 组织 -> 成员管理 -> 成员设置 -> 快速加入企业

规则：
- 开启后，HR 或管理员在员工花名册中导入含手机号的员工资料，员工登录后默认收到加入企业邀请
- 关闭后，必须由管理员主动邀请，员工才会收到加入企业邀请

## 2. 员工加入企业操作
员工注册并登录后，若企业已发起邀请，可直接点击加入企业。
若暂时没有邀请，则需等待管理员邀请或主动联系企业管理员。

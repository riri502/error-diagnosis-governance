# approval_management

## 这是什么

这是审批管理业务知识库的结构化目录，用于沉淀平台审批类能力，包括通用审批、审批角色、表单模板、数据管理和系统审批承接。

## 怎么用

- 先读 `00_领域概述.md` 了解审批管理域边界
- 再读 `10_审批管理.md` 理解审批能力结构与承接方式

## 阅读顺序

1. 领域总览层
2. 审批能力层

## 维护原则

- 只记录审批管理能力、角色和承接边界知识
- 不在本目录中写其他业务域的具体审批规则细节
- 尽量复用已有审批术语，避免新增审批概念
- 新知识优先落到对应编号模块，不回写为大一统长文

## 迁移原则

- 先沉淀审批管理的公共能力，再补充业务侧对接知识
- 与权限等治理域交叉时，只保留审批侧真源，不替代对方规则口径
- 后续新增审批材料按编号模块继续补齐

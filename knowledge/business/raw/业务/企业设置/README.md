# enterprise_settings

## 这是什么

这是企业设置业务知识库的结构化目录，用于沉淀企业在平台中的展示表达、品牌配置、信息展示和登录页个性化相关知识。

## 怎么用

- 先读 `00_领域概述.md` 了解企业设置域边界
- 再读 `10_企业信息展示.md` 理解企业信息展示
- 再读 `11_企业登录页自定义.md`、`12_企业文化.md` 理解登录页个性化与企业文化表达

## 阅读顺序

1. 领域总览层
2. 企业展示层
3. 品牌与文化表达层

## 维护原则

- 只记录企业展示、品牌配置和文化表达相关知识
- 不在本目录中写组织、成员或权限治理规则
- 尽量复用已有企业设置术语，避免新增展示配置概念
- 新知识优先落到对应编号模块，不回写为大一统长文

## 迁移原则

- 先沉淀企业展示主链路，再补充品牌和文化表达细节
- 与其他基础设置交叉时，只保留企业设置视角，不混入治理规则
- 后续新增企业设置材料按编号模块继续补齐

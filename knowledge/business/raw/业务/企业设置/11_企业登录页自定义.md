# 11_enterprise_login_page_customization

企业登录页个性化配置用于让企业拥有专属登录页展示。

## 1. 维护入口
路径：管理后台 -> 企业设置 -> 企业文化 -> 企业登录页配置

## 2. 开通方式
该能力通常需要联系专属客户经理或服务人员申请开通。

## 3. 支持范围
支持配置：
- Web 登录页
- H5 登录页

## 4. Web 页面可配置项
- 登录背景图
- 网页名
- 登录方式
- 按钮展示方式

## 5. H5 页面可配置项
- 应用名
- 网页标签
- 按钮展示方式

## 6. 使用效果
未配置时，企业使用平台官方默认登录 / 注册页。
配置后，企业用户需通过指定地址访问专属登录页。

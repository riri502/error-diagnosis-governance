# workspace_and_global_entry

## 这是什么

这是工作台与全局入口业务知识库的结构化目录，用于沉淀平台公共入口、工作台承载内容、全局导航和服务入口相关知识。

## 怎么用

- 先读 `00_领域概述.md` 了解本域边界与主题
- 再读 `10_工作台.md` 理解工作台的承载内容与入口角色
- 最后读 `11_全局导航与服务入口.md` 理解全局导航与服务入口的组织方式

## 阅读顺序

1. 领域总览层
2. 工作台承载层
3. 全局入口层

## 维护原则

- 只记录平台公共入口、工作台承载与导航服务入口相关知识
- 不在本目录中写业务域内部规则、审批细则或权限算法
- 尽量复用已有入口术语，避免新增入口概念
- 新知识优先落到对应编号模块，不回写为大一统长文

## 迁移原则

- 先建立入口认知，再补充各入口的承载差异
- 与具体业务域交叉时，只保留入口层语义，不替代业务真源
- 后续新增入口材料按编号模块继续补齐

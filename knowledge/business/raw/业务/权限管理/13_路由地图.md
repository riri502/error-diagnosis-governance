# 13_route_map

## 文件定位

本文件用于说明权限域内页面之间，以及权限域与外部治理模块之间的主要路由关系。

## 1. 配置链路

- `用户授权 -> 功能授权 -> 数据授权`
- `用户授权 -> 权限详情`
- `角色管理 -> 授权规则`
- `角色管理 -> 功能权限 / 数据权限`
- `权限管理模式 -> 子管理配置页`
- `权限管理模式 -> 双管理员模式配置页`
- `权限管理模式 -> 权限变更审批模式配置页`
- `应用管理 -> 应用设置页`

## 2. 解释链路

- `用户授权 -> 权限详情`
- `权限查询 -> 按用户查询结果`
- `按用户查询结果 -> 权限明细`
- `权限详情 -> 应用管理`

## 3. 外部治理链路

- `权限变更审批模式配置页 -> 审批管理`
- `权限变更审批模式配置页 -> 协同办公审批列表`
- `应用设置页 -> 通用审批`
- `功能授权 -> 应用中心`

## 4. 路由说明

- `用户授权 -> 功能授权 -> 数据授权` 是按人配置的主链路
- `角色管理 -> 授权规则` 是角色模板化授权向自动授权扩展的链路
- `权限管理模式 -> 子管理配置页 / 双管理员模式配置页 / 权限变更审批模式配置页` 是系统级治理链路
- `权限查询 -> 按用户查询结果 -> 权限明细` 是解释与排障链路，不负责配置
- `应用管理 -> 应用设置页` 是应用级入口治理与单应用管理员治理链路

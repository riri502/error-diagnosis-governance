# hr_service

## 这是什么

人事服务业务知识库，对应薪福通帮助中心"人事服务"模块。沉淀组织管理、员工管理、招聘管理、假勤管理、客户管理等相关知识。

- 来源：help/modules/人事服务/
- 来源类型：帮助中心采集产物

## 怎么用

- 先读 `00_领域概述.md` 了解人事服务域边界
- 再读 `org_management/` 了解组织管理（组织架构、编制、岗位、职级）
- 再读 `employee_management/` 了解员工管理（花名册、合同、任职异动）
- 再读 `recruitment/` 了解招聘管理（Moka集成）
- 再读 `customer_management/` 了解客户管理（客户全生命周期）
- 再读 `attendance/` 了解假勤管理（排班/打卡/考勤，仅产品介绍）

## 子域

| 子域 | 对应帮助中心模块 | 状态 |
|------|-----------------|------|
| org_management | 组织管理 | 部分入库 |
| employee_management | 员工管理 | 部分入库 |
| recruitment | 招聘管理 | 已入库 |
| attendance | 假勤管理 | 部分入库（仅产品介绍） |
| customer_management | 客户管理 | 已入库 |

## 维护原则

- 按帮助中心产品模块结构组织，保持与用户可见产品语言一致
- 不在此目录中写与其他一级模块（协同办公、费用管理等）交叉的知识
- 新知识优先落到对应子域，不回写为大一统长文

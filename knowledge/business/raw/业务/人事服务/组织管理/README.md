# org_management

## 这是什么

组织管理子域，对应薪福通帮助中心"人事服务 > 组织管理"模块。沉淀组织架构搭建、编制管控、岗位管理和职级管理相关知识。

## 怎么用

- 先读 `00_领域概述.md` 了解组织管理子域边界
- 再读 `10_组织架构.md` 理解组织架构搭建与架构图
- 再读 `13_编制管理.md` 理解编制管控机制
- 再读 `14_岗位与职级管理.md` 理解岗位与职级体系

## 与旧 organization 域的关系

本子域仅包含从帮助中心采集的组织管理知识。组织架构的基础维护知识仍保留在 `knowledge/raw/业务/组织架构/` 中。

## 维护原则

- 只记录帮助中心"组织管理"模块中的产品知识
- 不在本目录中写组织架构的通用抽象概念（这些保留在 organization 域）
- 新知识优先落到对应编号模块

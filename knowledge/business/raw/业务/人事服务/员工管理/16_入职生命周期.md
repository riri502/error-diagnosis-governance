# 16_employment_lifecycle

任职管理覆盖员工从入职到离职的全生命周期人事异动，支持全流程在线申请和审批。

- 来源：help/modules/人事服务/员工管理/
- 来源类型：帮助中心产品介绍 + 入职/协同操作指引
- 最近更新：2026-05-05

## 1. 人事异动类型

系统支持以下异动场景：
- 入职、转正、调动、兼任、临时调店、离职

## 2. 入职设置

路径：【员工管理-员工管理设置-基础设置-任职管理设置-入职设置】

### 2.1 入职流程设置
四项流程均可独立开启或关闭：
1. HR新增待入职
2. 员工扫码登记
3. 入职审批
4. 确认入职

### 2.2 扫码登记设置
- 可选择员工扫码时是否进行身份验证
- 可选择是否限制待入职人员扫码

### 2.3 待入职字段设置
勾选员工入职过程中需要填写的字段（按需选择）

### 2.4 入职事项设置
员工入职后可选择开启或关闭提示办理该事项。

### 2.5 新版本独有功能
- 入职年龄设置（避免用工风险）
- 自动确认入职（入职日期当天自动确认）

## 3. 入职管理

路径：【人事服务-员工管理-任职管理-入职管理】

### 3.1 待入职

#### 方式一：扫码入职（员工自助）
- 点击"新增待入职" → 录入姓名、手机号、证件类型、证件号码、入职部门等少量信息
- 开启邀请员工扫码登记，选择对应的入职二维码
- 提交后系统自动发送短信给员工
- 员工在手机端填写入职登记表剩余内容
- 员工填写完成后信息自动同步至待入职界面

#### 方式二：HR录入信息入职
- HR完成待入职全量信息的填写并提交
- 信息直接展示在待入职界面

#### 方式三：批量导入待入职
- 下载模板 → 批量填写待入职信息 → 导入系统
- 基于导入数据可正常进行发起审批、在线编辑、放弃入职、确认入职等操作

#### 待入职期间的更多操作
- 查看和编辑员工填写的待入职信息
- 提交审批（若设置了待入职审批流程）
- 放弃入职（信息进入"放弃入职"页面）
- 批量确认入职、批量邀请员工扫码登记

### 3.2 已入职

- 查看已入职员工信息
- 设置入职事项（合同签订、入职定薪、考勤机分配、考勤组分配、薪资组设置、社保方案设置等）
- 开启入职事项后，将在员工入职后提示该事项

### 3.3 放弃入职

- 查看放弃入职的人员信息
- 支持重新发起入职

### 3.4 入职办理完整流程（含审批）

**第一步：手工添加待入职人员**
通过【员工管理-任职管理-入职管理-待入职】中点击"新增待入职"，添加员工基本信息。

**第二步：创建入职二维码**
在"待入职"页面点击"入职二维码"，根据企业实际情况填写入职规则，自动生成二维码（可长期使用）。

**第三步：员工扫码**
支持招商银行App、微信或浏览器扫码。若开启"仅待入职员工可扫码"，则仅HR添加的待入职人员可扫码。

**第四步：入职信息审批（可选）**
需在OA审批中配置入职审批流程（路径：【管理后台-审批管理-通用审批-系统分组-员工管理-入职】）。审批人可在【OA审批-审批中心-待处理】或工作台"待办"中审批。

**第五步：确认入职**
支持单人确认和批量确认。完成入职后可在【入职管理-已入职】中查询。

### 3.5 录用审批方式入职

通过录用的方式发起录用审批，审批通过后员工自动进入待入职列表。

- 单个发起：【OA审批-发起审批】→ 选择"录用" → 填写表单提交
- 批量发起：【OA审批-高级功能-批量发起】→ 新建批次 → 选择"录用"表单 → 下载模板填写后上传
- 审批通过后，员工进入待入职状态，可在【入职管理-待入职】中查询

## 4. 入职协同

### 4.1 权限开启
路径：【管理后台-通用权限设置-用户授权-员工管理-基础设置】

### 4.2 协同事项设置
路径：【员工管理设置-基础设置-协同事项设置】

**系统预置事项（8类）：**
| 事项 | 默认启用 |
|------|---------|
| 合同签订 | ✓ |
| 考勤组设置 | ✓ |
| 考勤机设置 | ✓ |
| 生物特征采集 | ✓ |
| 社保方案 | ✓ |
| 入职定薪 | |
| 薪资组 | |
| 个税档案 | |

- 系统事项不支持删除，仅支持不启用（关闭启用开关）
- 可创建自定义事项，关联自定义字段和行政信息分组字段
- 配置仅对设置完成后的新入职员工生效

### 4.3 发起与处理
- 管理员确认员工入职后，系统根据设置的协同事项推送待办至工作台或手机提醒
- 协同事项看板展示每个入职事项办理进度
- 系统自动检查记录，有数据时自动更新为"已处理"
- 全部事项为已处理时，办结状态为"已办结"

### 4.4 协同看板时间字段
- 生成时间 = 员工确认入职后生成入职事项记录的时间
- 办结时间 = 最后一个入职事项完成的时间
- 办结周期 = 全部入职事项完成所耗总时长

## 5. 转正管理

### 5.1 转正规则设置

- 自定义设置转正消息提醒时间（计划转正日期前发送系统消息）
- 自定义设置转正待办提醒时间（计划转正日期前推送工作待办）
- 转正表单设置：在管理后台通用审批中选择转正表单进行流程设置
- 转正日期计算方式可配置
- 转正待办通知规则可配置

### 5.2 转正操作流程

**转正中：**
- 系统将待转正员工数量以浮标数字展示在"办理转正"按钮上
- 点击进入后查看需办理转正的员工，选择人员后点击"办理转正"
- 系统跳出转正表单供选择
- "转正中"界面展示的数据为转正流程中或流程结束但未到生效日期的转正信息

**已转正：**
- 支持信息查看及取消转正操作
- 取消转正后员工信息返回待转正页面
- 可通过"转正中"界面点击"办理转正"重新查看该员工

## 6. 调动管理

### 6.1 调动基础设置

- 调动表单及流程需提前配置（管理后台 → 通用审批 → 选择调动表单设置）
- 若调动不需要流程审批，删除所有审批节点即可
- 调动表单系统已预设一个，企业可复制多个进行调整
- 表单中必须包含"调动"套件

### 6.2 调动操作流程

- 在"调动中"界面选择"新增调动"
- 选择相应人员，点击确定后选择对应的表单（包含需填写的信息和审批流程）
- 已办理完的调动可在"已调动"界面查看信息
- 支持"取消调动"操作，取消后可在"全部调动记录"中查看并重新发起

## 7. 兼任管理

适用于同一员工须在多个部门任职的场景。

### 7.1 兼任管理设置

路径：【员工管理-员工管理设置-基础设置-任职设置-兼任管理设置】

- 点击"新增兼任"和"结束兼任"表单，对兼任的审批流程进行设置

### 7.2 新增兼任

- 在兼任管理界面点击"新增兼任"
- 填写员工信息及兼任的部门、开始日期等后提交
- 审批通过后在兼任管理界面生成兼任记录

## 8. 借调管理

### 8.1 借调管理设置

路径：【员工管理-员工管理设置-基础设置-任职设置-借调管理设置】

- 点击借调表单后的编辑按钮，对借调的审批流程进行设置

### 8.2 新增借调

- 在借调管理界面点击"新增借调"
- 选择对应员工并填写员工信息及借入的部门、开始日期等后提交
- 审批通过后在借调管理界面生成借调记录

## 9. 临时调店管理

### 9.1 临时调店设置

路径：【员工管理-员工管理设置-基础设置-任职设置-临时调店设置】

- 点击临时调店表单后的编辑按钮，对审批流程进行设置

### 9.2 新增调店

- 在临时调店管理界面点击"新增调店"
- 选择对应员工并填写员工信息及借入部门、开始日期等后提交

## 10. 离职管理

### 10.1 离职基础设置

路径：【员工管理-员工管理设置-基础设置】

使用前需提前配置：
- 离职流程设置
- 离职表单内容设置（管理后台 → 通用审批中设置）
- 是否启用离职交接规则（可开关控制，可设置为提交离职申请后或离职审批通过后发起交接）
- 是否自动确认离职
- 是否自动解除合同

### 10.2 办理离职

- 可针对单个或多名员工同时发起离职
- 单个员工：选择对应的离职表单进行内容填写
- 多名员工：系统校验离职表单信息通过后进入"离职中"界面
- 在"离职中"界面可继续确认离职或发起离职交接

### 10.3 离职交接

- 在"离职中"界面点击"离职交接"
- 选择相应的离职交接表单进行内容填写
- 离职交接流程需在管理后台通用审批中设置

### 10.4 确认离职与取消离职

- 离职交接审批完成或离职流程审批完成后，点击"确认离职"
- 点击"取消离职"则员工从"离职中"界面消失，恢复正常状态
- 在"已离职"界面可查看已离职员工信息，并支持"取消离职"操作

### 10.5 黑名单管理

- 员工离职时可加入黑名单（在发起离职页面选择或在"黑名单管理"中单独添加）
- 后续员工再次入职时系统会进行黑名单提示，供HR选择

### 10.6 离职记录

- 在"全部离职记录"中查看所有已通过、已撤销、已否决、已取消的离职记录
- 针对已撤销、已否决和取消离职的记录，点击"查看"后可重新发起离职

### 10.7 离职强校验/弱校验

确认离职时系统可能弹出提示信息，根据设置不同表现：

- **强校验**：员工存在费控/资产/福利等业务数据未处理时无法办理离职
- **弱校验**：仅提示，可选择继续办理离职

设置路径：【员工管理-员工管理设置-基础设置】→ 选择是否开启"员工离职强校验"

**常见弱校验及处理：**
1. 有待处理的审批 → 用户自行在审批中心处理；或管理员在【管理后台-审批中心-数据管理-审批交接】处理
2. 配置在审批角色中 → 在【管理后台-审批管理-通用审批-审批角色】中更新
3. 是某组织的组织负责人/审批主管 → 在【管理后台-组织管理-组织架构】中调整
4. 已加入客户项目服务 → 在【客户管理-用工管理】中退出项目
5. 被设置为汇报上级 → 在【员工管理-员工花名册】修改对应员工的汇报上级

**常见强校验及处理：**
1. 未还清的借款单/预付款 → 管理员在【财务处理-借还款管理-借款/预付管理】中操作转交或关闭
2. 流程中未完结的单据 → 管理员在【智能费控-财务处理-台账管理-单据台账】中查看处理
3. 作为部门管理员的资产 → 在【资产管理-资产清单-编辑】修改管理员
4. 名下未退还的资产 → 在【资产管理-资产清单】退还资产或管理员编辑"当前使用人"

## 11. 任职记录

## 12. 证明开具

路径：【员工管理-员工服务-证明开具】

### 12.1 模板管理

设置路径：【员工管理-员工服务-证明开具】→ "模板管理" → "新增"

- 可选择新增Word或Excel版本
- 在编辑区域输入证明内容
- 通过拖动模板变量快速获取员工证明类信息
- 模板内容填写完成后点击保存

### 12.2 开具证明

**第一步：发起**
点击"开具证明" → 选择员工和证明模板 → 点击"下一步"

**第二步：检查信息**
查看或编辑员工信息，重新选择人员后点击"预览并开具"

**第三步：开具证明**
预览信息无误 → 拖动公章到指定位置 → 点击发起 → 完成证明开具

支持同一模板选择多名员工进行批量处理。

## 13. 任职信息轻管理模式

### 13.1 功能背景

当前系统在花名册中直接修改人员信息时，不会在任职记录中生成修改痕迹。花名册信息与实际业务情况出现偏差时，需人工核对排查。因此，针对多人管理花名册的企业，可根据需要开启/关闭"任职信息轻管理模式"。

### 13.2 功能路径

进入【员工管理-员工管理设置-基础设置】，可开启或关闭"任职信息轻管理模式"。

### 13.3 开启/关闭说明

- **开启模式（默认）**：允许在花名册中直接修改部门、岗位等关键信息，适用于单人管理花名册的企业
- **关闭模式**：仅允许通过任职管理模块修改关键信息，确保任职信息的准确性和一致性

关键信息字段包括：部门、岗位、职位、职级、汇报上级、员工类型、业务分组等。

### 13.4 "零售连锁"联动开关

- 零售连锁从关闭→开启时，系统自动关闭"任职信息轻管理模式"并禁止修改，提示：已标记为零售连锁企业，当前不支持修改任职信息
- 零售连锁从开启→关闭时，"任职信息轻管理模式"仍保持关闭状态，但允许修改

### 13.5 任职信息校正功能

**适用场景**：关闭"任职信息轻管理模式"后，若发现员工入职时填写的部门或入职日期存在错误，可通过此功能修正（连锁门店行业常见场景）。

**操作方式**：关闭模式下且当前用户具备功能权限时，在员工花名册详情页右上角"更多操作"中找到"任职信息校正"功能，直接修改员工信息。

**功能限制**：
- 仅支持单个员工信息修改，暂不支持批量操作
- 修改操作不会触发档案变更审批流程
- 默认授权给超级管理员，支持权限配置

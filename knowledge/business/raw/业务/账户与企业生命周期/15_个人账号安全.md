# 15_personal_account_security

个人账号相关安全能力包括修改手机号、找回账号、修改密码、忘记密码和注销账号。

## 1. 修改手机号
入口包括：
- Web：头像 -> 个人账号 -> 修改手机号
- App：我的 -> 账号安全 -> 修改手机号

修改手机号前需要进行身份验证，通常包含：
- 人脸验证
- 短信验证码验证

新手机号若已在平台中注册，通常不能直接替换复用。

## 2. 账号找回
适用于：
- 原手机号无法接收验证码
- 忘记登录密码

常见入口包括：
- 短信验证码登录 -> 找回账号
- 密码登录 -> 忘记密码 -> 找回账号
- App 登录页 -> 找回账号

找回过程通常包括：
- 原账号信息校验
- 实名信息校验
- 人脸识别
- 新手机号验证

## 3. 修改密码与忘记密码
入口包括：
- Web：头像 -> 个人账号 -> 修改密码 / 忘记密码
- App：我的 -> 账号安全 -> 修改 / 重置
- 登录页 -> 忘记密码

重置密码时通常需要：
- 短信验证
- 人脸验证

密码要求通常包括：
- 长度 8-20 个字符
- 至少包含三种字符类型（大写字母、小写字母、数字、特殊字符）

## 4. 注销个人账号
注销前通常需要：
- 若本人是管理员，先完成管理员转让
- 退出所有企业 / 组织

注销过程通常需要：
- 人脸识别
- 短信验证码验证

注销成功后，个人账号的相关数据通常无法恢复。

# account_and_enterprise_lifecycle

## 这是什么

这是个人账号与企业生命周期业务知识库的结构化目录，用于沉淀管理员启用、员工启用、企业创建与认证、企业状态治理、管理员变更和个人账号安全相关知识。

## 怎么用

- 先读 `00_领域概述.md` 了解本域边界
- 再读 `10_开通路径.md`、`11_企业创建与认证.md` 理解启用与建企主链路
- 再读 `12_企业状态与变更.md`、`13_超级管理员变更.md` 理解企业状态与管理员变更
- 最后读 `14_账号常见问题.md`、`15_个人账号安全.md` 理解账号问题与个人安全

## 阅读顺序

1. 领域总览层
2. 启用与建企层
3. 企业状态与管理员治理层
4. 账号问题与安全层

## 维护原则

- 只记录账号启用、企业生命周期和管理员变更相关知识
- 不在本目录中写组织主数据或应用内部业务规则
- 尽量复用已有账号与生命周期术语，避免新增阶段概念
- 新知识优先落到对应编号模块，不回写为大一统长文

## 迁移原则

- 先建立账号与企业生命周期主线，再补充异常问题和安全知识
- 与成员、权限等领域交叉时，只保留本域主线，不替代其他真源
- 后续新增生命周期材料按编号模块继续补齐

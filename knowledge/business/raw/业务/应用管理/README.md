# app_management

## 这是什么

这是应用管理业务知识库的结构化目录，用于沉淀企业已启用应用治理、应用可见范围和组装应用相关知识。

## 怎么用

- 先读 `00_领域概述.md` 了解应用管理域的范围
- 再读 `10_应用管理.md` 理解应用治理与可见范围
- 最后读 `11_应用组装.md` 理解组装应用相关知识

## 阅读顺序

1. 领域总览层
2. 应用治理层
3. 组装应用层

## 维护原则

- 只记录应用治理、应用可见范围与应用组装相关知识
- 不在本目录中写用户授权算法或审批流程内部实现
- 尽量复用已有应用术语，避免新增应用治理概念
- 新知识优先落到对应编号模块，不回写为大一统长文

## 迁移原则

- 先沉淀应用台账与可见治理，再补充应用扩展与组装知识
- 与权限域交叉时，只保留应用治理口径，不覆盖权限真源
- 后续新增应用管理材料按编号模块继续补齐

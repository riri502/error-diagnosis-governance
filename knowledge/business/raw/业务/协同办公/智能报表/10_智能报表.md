# 10_smart_reports

智数报表是薪福通体系内企业数据可视化展示与交互管理的核心模块。

- 来源：help/modules/协同办公/智数报表/
- 来源类型：帮助中心产品介绍 + 6篇操作指引
- 最近更新：2025-10-12

## 1. 报表中心

### 1.1 分类展示
- 默认分类：我的收藏、未分类（置顶）
- 业务分类：人事服务、薪税代发、智能财务、协同办公、团体福利、智能费控、综合分析
- 管理员创建的分类是公司级的，所有用户可用
- 每个分类默认展示第一行数据，展开查看全部

### 1.2 报表查阅
- 点击卡片进入报表详情
- 全屏查阅、导出查阅（Excel/PDF/图片，需导出权限）
- 卡片放大、数据显示（查看可视化背后的数据结构）
- 支持钻取、联动等高级分析场景

### 1.3 报表收藏
- 一键收藏/取消收藏，PC和移动端均支持
- 收藏报表归入顶部"我的收藏"分类

### 1.4 修改报表
修改报表按钮需同时满足4个条件：
1. 员工有报表授权权限（主题报表或模板市场启用的个性化报表）
2. 员工有智数平台开发报表权限
3. 对应的官方报表(模板)已上架且企业有权限
4. 官方报表(模板)引用的数据集模型已上架且企业有权限

## 2. 报表授权

以单张报表为维度：
- 用户授权：最多20位员工
- 角色授权：批量管理（推荐），最多20个角色
- 可授权：查看、导出、授权（将该报表授权给他人）
- 数据权限配置前，数据集字段需绑定平台维度（在智数平台完成）

## 3. 报表停用与启用

适用场景：
- 隐藏未使用业务模块的预置报表
- 临时关闭需修改或紧急下架的报表
- 停用后权限保留，启用即可恢复

## 4. 报表订阅

- 目前仅支持邮件订阅
- 创建订阅：选择报表→选择收件人→校验邮箱→设置推送时间/频率（日/周/月）
- 系统自动过滤无权限用户，默认读取花名册邮箱（可修改）
- 收件人点击邮件链接跳转查看报表内容

## 5. 报表预警

- 预设的主题报表暂不支持预警
- 最多添加5条预警规则
- 预警规则包含：名称 + 维度条件 + 数值条件
- 多条规则可选触发条件：满足所有/满足任一
- 触发时间：更新后通知 或 定时通知（日/周/月）
- 通知渠道：薪福通消息、薪福通待办、邮件
- 通知标题≤20字符，内容≤2000字符
- 普通员工仅可见"我接收的"；应用管理员可见全部功能

## 6. 角色与权限体系

| 角色 | 权限 |
|------|------|
| 普通员工 | 仅查看被授权报表 |
| 单张报表管理员 | 对该报表授权（齿轮图标） |
| 智数报表应用管理员 | 可对其他员工授权 |
| 业务管理员 | 有"权限管理"菜单时可对企业所有报表授权 |
| 超级管理员 | 唯一一位，可查看所有报表和所有管理菜单 |

## 7. 市场薪酬查询

### 7.1 使用方式
- 按岗位名称搜索，查看与该岗位相关的所有岗位薪酬信息
- 按职能分类筛选，查看该职能下所有岗位薪酬信息
- 筛选条件：市场范围、职能、职级
- 点击卡片查看岗位详细信息（需加入认证企业）

### 7.2 指标含义

| 指标 | 含义 |
|------|------|
| **年固定薪酬** | 年基本薪酬 + 年固定现金津贴 |
| **年基本薪酬** | 全职员工的税前12个月基本薪酬或固定薪酬 |
| **年固定现金津贴** | 包括固定发放的13薪、岗位津贴、住房津贴、餐补、通讯津贴、交通及其它固定发放的津贴或补贴 |
| **年总现金收入** | 年固定薪酬 + 年浮动薪酬（如：奖金、佣金/销售激励）。不含股票期权等长期激励 |
| **25分位** | 将适用的样本数据从小到大排列后，只有25%的数据小于此数值。反映市场较低水平 |
| **50分位** | 将适用的样本数据从小到大排列后位置居中的数，又称"中位值"，反映市场的中等水平 |
| **75分位** | 将适用的样本数据从小到大排列后，75%的数据小于此数值。反映市场的高端水平 |
| **90分位** | 将适用的样本数据从小到大排列后，90%的数据小于此数值。反映市场的极高端水平 |
| **平均值** | 平均值是样本值之和除以样本个数得出的。平均值不同于中位值，平均值受到样本中所有数值的影响，容易受极端值影响；而中位值仅代表中点的值，不受极端值影响 |

### 7.3 明确规则
- 未加入认证企业的用户无法查看岗位详细信息
- 筛选条件支持市场范围、职能、职级三个维度
- 在查阅报表时，若报表被设计有钻取、联动等高级分析场景，可在查阅时进一步做数据挖掘

## 8. 定制化报表验收

- 路径：【智数报表-待验收报表-待我验收】
- 验收通过：报表直接发布
- 验收拒绝：填写拒绝原因，重新进行报表开发优化

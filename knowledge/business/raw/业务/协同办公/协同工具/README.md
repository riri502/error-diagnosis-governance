# collaboration_tools

协同工具子域，对应薪福通帮助中心"协同办公 > 协同工具"模块。包含通讯录、企业公告、公文、信息收集、必应、智能会议室、日程共7个工具。

## 怎么用

- 先读 `00_领域概述.md` 了解协同工具子域边界
- 再读 `10_协同工具.md` 理解全部工具功能

## 工具索引

| 工具 | 核心功能 |
|------|---------|
| 通讯录 | 企业员工信息管理，与花名册实时互通 |
| 企业公告 | 内部公告发布与管理 |
| 公文 | 文件电子化管理与流转 |
| 信息收集 | 问卷/补录表单收集 |
| 必应 | 个人/团队待办事项管理 |
| 智能会议室 | 会议室数字化管理 |
| 日程 | 日程创建/订阅/管理 |

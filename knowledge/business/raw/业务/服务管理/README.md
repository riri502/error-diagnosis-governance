# service_management

## 这是什么

这是服务管理业务知识库的结构化目录，用于沉淀企业邀请服务人员、配置服务时间和授权范围、并记录服务行为的相关知识。

## 怎么用

- 先读 `00_领域概述.md` 了解服务管理域边界
- 再读 `10_服务人员授权.md` 理解服务人员授权与服务治理

## 阅读顺序

1. 领域总览层
2. 服务人员治理层

## 维护原则

- 只记录服务人员接入、授权范围和服务治理知识
- 不在本目录中写通用权限算法或成员域主链路知识
- 尽量复用已有服务管理术语，避免新增服务治理概念
- 新知识优先落到对应编号模块，不回写为大一统长文

## 迁移原则

- 先建立服务人员治理主链路，再逐步补充服务行为与约束知识
- 与成员、权限域交叉时，只保留服务管理视角，不覆盖其他真源
- 后续新增服务管理材料按编号模块继续补齐

# DOC-11 上线与回检准备登记规则

> 阶段：Phase 8 | 阻断性：否（回检前完成即可）

## 适用对象
已进入开发排期并完成上线的条目，或通过文案/配置平台发布完成的条目。

## 输入字段
治理条目ID / 错误码 / 优化类型 / 上线时间 / 上线版本 / 上线范围 / 灰度/全量 / 影响页面路由 / 关联埋点事件 / 埋点文档路径 / 指标口径说明

## 输出
上线与回检准备记录：是否具备回检条件 / 推荐回检开始时间 / 回检周期 / 是否进入已上线待回检池

## 回检就绪检查
- 有实际上线时间（必须）
- 有上线范围（必须）
- 有主指标（必须）
- 有数据获取方式（必须）
- 有埋点口径或文档（必须）
- 不满足→待补充上线信息池或埋点口径待确认池，不触发自动回检

> 详细规则待 Phase 8 前补充

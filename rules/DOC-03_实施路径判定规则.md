# DOC-03 实施路径判定规则

> 阶段：Phase 1 | 阻断性：准阻断

---

## 四类路径

| 路径 | 适用情况 | 主要交付物 |
|------|---------|----------|
| A. 纯文案发布 | 只改文案，不改组件/时机/逻辑 | 文案发布包 |
| B. 配置化体验 | 平台可配帮助链接/按钮/样式/跳转 | 配置清单 + 发布包 |
| C. 前端交互改造 | 改提示形式/时机/页面状态/弱打断 | 交互说明 + 状态规格 |
| D. 后端规则逻辑 | 改校验规则/接口返回/错误码/业务逻辑 | 需求说明 + 规则调整 |

## 判定流程

```
涉及后端接口/校验逻辑/错误码变更？→ 是 → D
仅涉及前端提示形式/时机/状态？   → 是 → C
平台可配置完成？                  → 是 → B
仅文案内容？                     → 是 → A
```

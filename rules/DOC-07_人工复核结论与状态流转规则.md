# DOC-07 人工复核结论与状态流转规则

> 阶段：Phase 1 | 阻断性：阻断

## 复核结论枚举

| 结论 | 后续状态 |
|------|---------|
| 评估准确，进入治理 | 治理候选池 |
| 评估基本准确，需调整建议 | 待调整建议 |
| 评估不准确 | 规则修正池 |
| 条目暂未复现 | 暂未复现池 |
| 条目无需优化 | 无需优化归档 |
| 需补充信息 | 待补充信息池 |
| 需产品确认 | 产品确认池 |
| 需研发确认 | 研发确认池 |
| 需补充埋点 | 埋点缺口池 |

## 状态流转

```
待评估 → 诊断中 → 待人工复核 →
  ├─ 治理候选
  ├─ 暂未复现
  ├─ 无需优化
  ├─ 待补充信息
  ├─ 规则修正
  └─ 埋点缺口
```

治理条目ID / 报错文案 / AI诊断摘要 / 建议路径和优先级 / 证据摘要 / 人工结论 / 复核人 / 复核时间 / 备注

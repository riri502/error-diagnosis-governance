# DOC-00 数据源盘点与输入输出契约

> 阶段：Phase 0 | 阻断性：阻断 — Step 2-5 多源检索的基础

---

## 1. 输入报错表

| 字段名 | 别名 | 类型 | 缺失处理 |
|--------|------|------|---------|
| 错误码 | error_code, code, 报错码 | string | 进入待补充信息池 |
| 报错提示 | error_msg, 报错文案, 错误提示 | string | **必填，不可缺失** |
| URL | 页面URL, 请求URL, 链接 | string | 可为空 |
| 页面路由 | 路由, 页面路径, 路径 | string | 可为空 |
| 触发场景 | trigger_scenario | string | 进入待补充信息池 |
| 页面报错次数 | 报错次数, error_count | int | 默认为 1 |

---

## 2. 去重汇总表

关联键：(错误码 + URL + 页面路由) → 输入报错表

---

## 3. 归类汇总表

关联键：(报错提示) → 去重汇总表。含大类/小类/任务类型/校验逻辑/报错原因等字段。

## 4. 客户反馈源

| 项目 | 说明 |
|------|------|
| 关联键 | 错误码 / 业务模块关键词匹配 |

## 9. 缺失降级约定

| 缺失情况 | 降级策略 | 阻断？ |
|---------|---------|:---:|
| 客户反馈/工单/埋点/知识库不可用 | 跳过对应 Step，标注不可用 | 否 |
| 错误码为空 | 进入待补充信息池 | 是 |
| 报错提示为空 | 无法继续 | 是 |

# DOC-05 成效预估与可信度规则

> 阶段：Phase 1 | 阻断性：准阻断

## 核心原则

所有成效预估必须标注可信度。不得在证据不足时输出确定性收益结论。

## 可信度等级

| 等级 | 条件 |
|------|------|
| **高** | ≥ 3 源数据指向一致（历史案例+埋点+客户反馈+体验标准）|
| **中** | 2 源可用，趋势一致 |
| **低** | ≤ 1 源或全靠推断 → 仅定性描述 |

## 输出格式

```
预计成效：
- 主指标：{名}，预估 {方向+区间}
- 可信度：{高/中/低}
- 依据：{来源列表}
- 限制：{缺失数据/风险}
```

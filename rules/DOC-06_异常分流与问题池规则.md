# DOC-06 异常分流与问题池规则

> 阶段：Phase 1 | 阻断性：阻断

## 问题池清单

| 池 | 进入条件 | 后续动作 |
|----|---------|---------|
| 待评估池 | 新增高频报错，未诊断 | 进入 SKILL-01 |
| 治理候选池 | AI 诊断准确，人工确认 | 进入方案设计 |
| 暂未复现池 | 人工无法复现 | 定期复核 |
| 无需优化归档 | 报错合理，正常拦截 | 归档 |
| 待补充信息池 | 缺关键字段/截图/路径 | 补充后重诊 |
| 低置信诊断池 | AI 置信度低 | 人工复核/规则修正 |
| 规则修正池 | AI 评估不准确 | 生成规则修正候选 |
| 埋点缺口池 | 无法判断影响/回检 | 生成埋点方案 |
| 已上线待回检池 | 优化完成且回检就绪 | 等待回检 |
| 待补充上线信息池 | 缺上线时间/范围 | 人工补充 |
| 埋点口径待确认池 | 口径不确定 | 补充文档 |

> 详细触发条件和阈值待补充

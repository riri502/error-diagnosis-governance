# SKILL-01 报错评估诊断

## 目标
输入报错，输出诊断报告和人工复核卡。

## 输入
- 单条报错字段：错误码、报错提示、URL、页面路由、触发场景、页面报错次数
- 或批量报错表（CSV/Excel）

## 输出
- 综合诊断报告（Markdown）
- 证据清单（含相关性等级）
- 路径建议（A/B/C/D）
- 人工复核卡

## 依赖规则
DOC-00（数据契约）→ DOC-01（分类）→ DOC-08（证据检索与相关性）→ DOC-02（体验标准）→ DOC-03（路径判定）→ DOC-04（优先级）→ DOC-05（可信度）→ DOC-06（异常分流）→ DOC-07（人工复核）

## 内部子步骤

```
01 输入标准化 → 校验必填字段，缺失分流
02 报错特征提取 → 按 DOC-01 归类
03 检索关键词生成 → 从报错特征中提取用于多源检索的关键词组合
04 多源证据检索 → 按 DOC-00 的字段契约，在客户反馈/工单/埋点/知识库中检索
05 证据相关性判定 → 按 DOC-08 对检索结果进行相关性分级（强/中/弱/不相关）和冲突处理
06 体验问题评估 → 按 DOC-02 四维度评估
07 优先级评分 → 按 DOC-04 五维加权评分
08 成效预估与可信度判断 → 按 DOC-05
09 实施路径判定 → 按 DOC-03
10 综合诊断报告生成 → 按 report_template.md
11 人工复核卡生成 → 按 review_card_template.md
```

## 每步校验
- 输出是否符合预期格式
- 置信度是否达到阈值
- 异常是否分流到正确问题池

# 工具总体架构说明

## 三阶段闭环

评估诊断 → 实施上线 → 回检闭环 → 知识沉淀（反哺下一轮评估诊断）

## 六层结构

- 评估诊断层：报错输入 → 多源检索 → 交叉分析 → 综合诊断报告
- 运行控制层：运行记录 → 异常捕获 → 问题池分流 → 人工复核卡 → 结论回写
- 实施上线层：路径判定 → 方案设计/发布包/配置/平台发布/开发排期
- 上线与回检准备层：上线登记 → 埋点口径确认 → 回检就绪检查
- 回检闭环层：数据拉取 → 成效判定 → 延长观察/复诊/归档
- 知识沉淀层：成功案例/踩坑记录/规则修正 → 反哺诊断

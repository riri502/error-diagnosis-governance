# HARNESS-MVP 状态流转

```
待评估 → 诊断中 →
  ├─ 输入标准化
  ├─ 特征提取
  ├─ 检索关键词生成
  ├─ 多源证据检索
  ├─ 证据相关性判定 →
  │   ├─ 证据充分 → 体验问题评估 → 优先级评分 → 成效预估 → 路径判定 → 报告生成 → 复核卡生成
  │   ├─ 证据不足 → 证据不足池 / 低置信诊断池 / 待补充信息池 / 埋点缺口池
  │   └─ 证据冲突 → 证据冲突池（需人工确认/需产品确认/需运营确认）
  ↓
待人工复核 → 人工复核完成 →
  ├─ 治理候选池 → 方案设计中 → 待发布 → 已上线 → 待回检 → 回检中 → 回检完成 → 已归档
  ├─ 暂未复现池 → 定期复核
  ├─ 无需优化归档
  ├─ 待补充信息池 → 重新诊断
  ├─ 规则修正池 → 生成规则修正候选
  ├─ 埋点缺口池 → 生成埋点方案
  ├─ 证据不足池 → 补充证据后重新诊断
  └─ 证据冲突池 → 人工确认后分流
```

状态枚举值：待评估 / 诊断中 / 证据检索中 / 证据相关性判定中 / 待人工复核 / 人工复核完成 / 方案设计中 / 待发布确认 / 已发布 / 已上线 / 待回检 / 回检中 / 回检完成 / 已归档

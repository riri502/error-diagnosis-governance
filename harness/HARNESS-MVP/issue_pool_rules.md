# HARNESS-MVP 问题池分流规则

触发时机与分流目标：见 `rules/DOC-06_异常分流与问题池规则.md`

## 自动分流逻辑
- Step 1 输入缺字段 → 待补充信息池
- Step 4 所有源不可用 → 低置信诊断池
- Step 5 证据不足 → 证据不足池
- Step 5 证据冲突 → 证据冲突池（需人工确认）
- Step 5 只有弱相关证据 → 低置信诊断池
- Step 6 置信度 < 阈值 → 低置信诊断池
- 其余 → 待人工复核（由复核结论决定最终分流）

## 证据类分流规则（DOC-08 驱动）

| 情况 | 分流结果 |
|------|---------|
| 没有任何可用证据 | 证据不足池 |
| 只有弱相关证据 | 低置信诊断池 |
| 客户反馈强相关，但埋点缺失 | 埋点缺口池 + 允许定性判断 |
| 埋点高频，但客户反馈缺失 | 标记"高频待确认"，进入人工复核 |
| 工单显示已治理，但埋点仍高 | 规则修正池 |
| 业务知识库与客户反馈结论冲突 | 证据冲突池（需产品确认）|
| 设计知识库与现网形式冲突 | 规则修正池 |
| 证据来源不可访问 | 待补充信息池 |

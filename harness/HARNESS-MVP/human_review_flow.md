# HARNESS-MVP 人工复核流程

## 流程
```
SKILL-01 生成诊断报告 + 复核卡（含证据清单）
        ↓
人工审核（设计/产品/运营/研发）
        ↓
复核：AI 结论是否准确 + AI 引用的证据是否有效
        ↓
填写复核结论（枚举值，见 DOC-07）
        ↓
回写治理台账（state/governance_ledger_template.csv）
        ↓
根据结论分流到对应问题池
```

## 证据复核项（DOC-08 驱动）

人工复核时需确认：
- 证据是否与报错场景相关？
- 证据是否完整？
- 是否遗漏关键反馈/工单/埋点？
- 是否存在错误引用？
- 是否存在证据冲突？
- 是否需要补充证据？
- 是否需要补充埋点？

## 证据相关人工结论

- 证据充分，诊断可信
- 证据基本充分，但需补充说明
- 证据不足，暂不进入治理
- 证据引用不准确，需重新检索
- 证据冲突，需产品/运营确认
- 埋点证据缺失，需补充埋点

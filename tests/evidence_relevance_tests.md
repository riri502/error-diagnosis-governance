# 证据相关性测试

| 测试项 | 输入 | 预期 |
|--------|------|------|
| 错误码一致 + 页面一致 | 同错误码 + 同页面路由 | 强相关 |
| 只有业务模块一致 | 同模块但不同错误码/页面 | 弱相关 |
| 同一错误码但不同业务场景 | 只有错误码一致 | 不应判强相关 |
| 客户反馈时间距离过远 | 反馈时间与报错高峰相差 > 3 月 | 相关性降低 |
| 埋点数据缺失 | 无埋点源 | 标记数据源不可用或证据不足 |
| 工单显示已治理但埋点仍高 | 工单"已解决"+ 埋点高频 | 标记证据冲突 |
| 知识库命中但缺真实数据 | 有知识库匹配但无埋点/反馈 | 可支撑场景判断，不能支撑影响规模 |
| 客户反馈强但报错量低 | 反馈强烈 + 报错次数 < 100 | 标记"低频高痛点" |
